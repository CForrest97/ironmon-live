# Bounded contexts

Bounded contexts capture distinct language, responsibilities, rules, and
relationships. Start with [`_template.md`](_template.md), allocate the next
unused `CTX-###` ID, and update the context map.

Do not use a context document as an early class diagram. Tactical constructs
such as aggregates, repositories, and domain events should be modeled only when
concrete behavior makes them useful.
