# Replace with a bounded context title

## Purpose

Explain the domain capability and why it needs a distinct language or model.

## Language

Define context-specific terms and link shared glossary entries.

## Responsibilities

Describe what this context owns and decides.

## Invariants

List rules that must always hold inside the boundary.

## Boundaries

State what is inside and explicitly outside the context.

## Integrations

## Context Relationships

state `None.`

## Decisions
