# Agent learnings

Learning records are durable, reviewable memory derived from corrections,
failed checks, review feedback, and unexpected outcomes. They help future agents
change behavior without silently rewriting product truth.

Use [`_template.md`](_template.md), allocate the next unused `LRN-###` ID, and
link the learning from the work item that produced it.
