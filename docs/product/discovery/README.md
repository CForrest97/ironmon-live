# Discovery notes

Discovery notes hold observations, interviews, experiments, and other evidence.
They are informative, not authoritative. Use
[`_template.md`](_template.md) and name notes `YYYY-MM-DD-short-name.md`.

Product specifications should link the evidence that supports their problem
and requirements.
