# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature for this repository when available. If it is
not available, contact the repository owner privately through their GitHub
profile and include reproduction details and the likely impact.

You can expect acknowledgement within seven days. Please avoid disclosing the
issue publicly until a fix or mitigation has been agreed.

## Supported versions

There is no released application yet. Repository automation on `main` is the
only currently supported version.
